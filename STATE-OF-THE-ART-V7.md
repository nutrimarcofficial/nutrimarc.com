# NutriMarc State-of-the-Art V7

V7 adds a luxury digital experience layer over the verified V6 application: experience rail, floating quick-action dock, premium glass surfaces, richer motion, reveal-on-scroll, pointer spotlight, elevated product/bootcamp cards, and refined responsive behavior. Core ordering, coupon, checkout, NAIS registration, CSR, enquiry, and backend code are retained.

Production payment/email credentials remain environment variables and must be configured on the deployed backend.
